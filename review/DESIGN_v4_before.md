# 精華剪輯器（FlashCut 替代）— 設計文件 v4

> 平台：macOS（Apple Silicon）、Windows 11 on ARM。技術：Python 3 + PySide6（QtMultimedia）+ ffmpeg。介面：繁體中文。
> 核心理念：**「匯入 → 勾選 → 產生成品」三步完成**；每一步都能手動接管。
> v4 依獨立審核報告（review/REVIEW.md）修正 14 項必改、全部建議與可選項，並新增素材庫、資料夾監看、刪除流程、智慧評分。對照表見 §10。

## 1. 功能清單

### 1.1 匯入
- **匯入影片**（⌘O／Ctrl+O）：不限數量，MP4／MOV／M4V／Insta360 `.LRV`；`.INSV` 以 MP4 嘗試開啟，失敗時顯示錯誤卡（§5）。
- **匯入資料夾**（⇧⌘O／Ctrl+Shift+O）：對話框顯示「找到 128 支，96 支已在素材庫且未變更（沿用分析結果），32 支待分析」；選項「包含子資料夾」（預設開）、「持續監看此資料夾」（預設開）。
- **監看**：App 開啟時每 30 秒、以及視窗重新取得焦點時重新掃描監看資料夾（`QFileSystemWatcher` + 定期掃描備援，外接硬碟也可用）；發現新檔顯示藍色橫幅「發現 2 支新影片，已加入並開始分析」。監看資料夾在「設定 › 素材庫」管理。
- 拖放檔案／資料夾到視窗任何位置；重複檔自動略過；以 `._` 開頭的 macOS 中繼檔與隱藏資料夾略過。

### 1.2 素材庫與分析快取（持久化）
- SQLite 素材庫位於應用程式資料夾：macOS `~/Library/Application Support/HighlightEditor/`、Windows `%LOCALAPPDATA%\HighlightEditor\`。
- 每支檔案以 **路徑 + 大小 + 修改時間 + 部分雜湊（頭尾各 1 MB + 大小）** 為鍵；儲存長度、解析度、有無音軌、分析分數、候選片段、預覽 proxy、縮圖。
- 重開 App 不重新分析；只有新檔或已變更檔會分析。檔案被搬移／改名但內容相同 → 依雜湊自動沿用。
- 狀態徽章（文字 + 底色，不只靠顏色）：**已分析**（綠）、**分析中 n%／待分析**（黃）、**已變更**（紫，附「重新分析」）、**錯誤**（紅，附「說明」「移除」）、**遺失**（紅，附「重新指定位置…」）。
- 分析中途關閉 App：重開後未完成的檔案仍為「待分析」，自動續跑（續作對話框會提示）。
- 「重新分析」：單支（右鍵／已變更列按鈕）或全部（設定 › 素材庫）；重新分析時保留手動片段與已勾選片段的微調。
- 快取管理（設定 › 素材庫）：顯示快取大小與影片數、上限（5 GB／10 GB／不限，超過時先刪最久未用的 proxy）、「清除預覽快取（保留勾選）」——清除後勾選、微調、順序都保留，proxy 在需要時重產。

### 1.3 自動候選片段
- 每支影片 **N 段候選**（預設 4，設定 1–10），長度預設 4 秒（2–10），**預設勾選每支最佳 2 段**（0–5 可調）。
- 基本評分（永遠可用，完全離線）：2fps 64×36 灰階影格差異（動態）＋ 0.5 秒 RMS 音量 ＋ 場景切換加分 → 平滑 → 取不重疊最高分窗，起點對齊場景切換。
- **選用：本機臉部／笑容／清晰度評分**（設定 › 智慧評分，預設關）：OpenCV（Laplacian 變異數算清晰度、模糊段扣分）＋ MediaPipe Face Detection／Face Landmarker（臉數、臉部面積、嘴角上揚與張嘴程度估計笑容）。完全離線、模型隨 App 打包、不需帳號或金鑰；只在候選窗內每秒取 2 格以控制耗時。未安裝套件時此選項顯示「需要額外元件（約 40 MB）・下載」並停用。
- **選用：雲端 AI「描述你想要的畫面」**（預設關）：在設定開啟並填入**使用者自己的 API 金鑰**（OpenAI 相容 API／Google Gemini／xAI；金鑰存在 macOS 鑰匙圈／Windows 認證管理員，不寫入素材庫）後，卡片牆上方出現描述框（例：「小孩在海邊笑」）。App 先用本機評分取前 30 個候選窗，每窗上傳 1–3 張 256px 關鍵影格與描述文字，模型回傳相符分數與一句說明，結果以「AI 相符」標記加到卡片並可一鍵勾選。描述框旁永遠顯示「會上傳低解析度關鍵影格」；未開啟時完全不發出任何網路請求。
- **迷你影片預覽卡**：每段產生 180p／15fps／靜音 proxy MP4，進入可視範圍自動靜音循環（同時上限預設 8，設定 4–16），超出範圍暫停並釋放解碼器。「減少動態」開啟時不自動播放，只在滑鼠移入或鍵盤焦點時播放。
- 卡片資訊：時間區間、長度、星等（1–5，含文字給讀屏）、勾選框（✓ 圖示 + 黃框 + `role=checkbox`）；畫面比例非 16:9 時疊上**裁切框**（框外 50% 黑色遮罩）。
- 卡片動作：點一下／空白鍵勾選；Enter 或「微調」（ghost 按鈕）進精修；右鍵選單：在大預覽播放、複製片段、刪除片段。
- 每組標題列：可收合（▾）、「4 段候選・已選 2」、「重新推薦」（彈出選單可改本組推薦數與長度，保留已勾選）、「＋ 手動新增片段」。

### 1.4 精修面板
- 有聲大預覽 + 能量曲線時間軸：**AI 候選標記**（藍色上緣條）、**目前範圍**（黃色把手，可拖曳，`role=slider`，聚焦時 ←/→ 0.1 秒、Shift ±1 秒）、**播放頭**（白線）。
- 數值輸入入點／出點；I／O 設定；←/→ 逐格；空白鍵播放／暫停；「播放此段」循環；「還原 AI 建議」；「套用」。套用後背景重產 proxy，卡片顯示讀取圖示直到完成。

### 1.5 時間軸（成品順序）
- 勾選即加入；**預設依拍攝時間排序**（讀 `creation_time`，沒有則用檔案修改時間；跨相機不亂序），可在設定改為匯入順序／AI 分數，時間軸右鍵也可「重新排序」。
- 片段寬度 = 秒數 × 22px（最小 48px）；底部 20px 半透明黑底文字帶（白字 12px，對比 ≥ 7:1）；右上 × 按鈕視覺 24px、點擊區 32×32，`aria-label="移除第 n 段"`。
- 拖曳排序；鍵盤：←/→ 移動焦點、⌘↑/↓（Windows：Ctrl+↑/↓）或 Alt+←/→ 移動片段、Delete 移除、Enter 精修。
- 摘要（不換行）：「已選 9 段・36.5 秒 / 目標 30 秒・超過 6.5 秒，將依比例縮短」（超出時橘色 #FFA000）。
- 「預覽成品」：在預覽區以低解析度 proxy 串播，顯示「預覽成品 00:08 / 00:24（低解析度）」與進度條。
- 選取持久化：勾選、微調、順序隨時寫入素材庫，重開後完全還原。

### 1.6 成品設定（右側面板）
- **成品長度**（最上方）：自動（全部已勾選）／15／30（預設）／60 秒／自訂。超過目標時，產生時各片段依比例從兩端等量縮短（最短 1.5 秒）；選「自動」則不縮短。
- 畫面比例 16:9／9:16／1:1（分段控制：`QButtonGroup` + checkable `QToolButton`，←/→ 切換）；解析度 1080p／4K；轉場：交叉淡化（0.5 秒，可在進階調 0.2–1.5）／無。
- 背景音樂：預設音樂資料夾下拉（含「隨機」）、選擇其他檔案、無音樂；自動循環或裁切為影片長度並在結尾淡出。
- 音樂音量、原音音量（標籤即時顯示百分比），保留原音開關；結尾淡出 0–5 秒（預設 1.5）。

### 1.7 產生成品
- 右下角唯一主要按鈕「產生成品」（⌘↩／Ctrl+Enter）。未勾選時停用，左側顯示可見文字「請至少勾選 1 個片段」。
- 流程：選擇儲存位置（預設「精華_YYYYMMDD_HHMM.mp4」於上次資料夾）→ **立即檢查磁碟空間**（估算 = 位元率 × 長度 × 1.3 + 暫存），不足時跳「磁碟空間可能不足」（選擇其他位置／仍要繼續／取消）→ 進度對話框。
- 進度：整體進度條（`role=progressbar`）+「步驟 2/3：合併與轉場・整體 62%・約剩 40 秒」+ 步驟清單（1 處理片段 8/8 ✓、2 合併與轉場、3 混音與輸出）。取消（或 Esc）先確認「要停止產生嗎？已處理的暫存檔會被刪除」。
- 完成：檔名、長度、解析度、**檔案大小**；按鈕：播放、在 Finder 中顯示（Windows：在檔案總管中顯示）、**另存 9:16 直式版**（沿用片段與設定，只改比例）、關閉。
- 編碼：預設 libx264；**硬體編碼**選項（設定 › 效能，Apple Silicon 預設開）：macOS `h264_videotoolbox`、Windows `h264_mf`；啟動時以 0.2 秒測試編碼確認可用，失敗自動退回 libx264。

### 1.8 移除與刪除
- 左欄支援多選（Shift／⌘ 或 Ctrl 點選、Shift+↑/↓、⌘A／Ctrl+A），底部「已選 3 支・移除…」。Delete 鍵亦可。
- 「移除 3 支影片」對話框列出檔名與數量，兩種選擇：
  - **從清單移除**（主要、預設焦點）：原始檔保留，從專案清單移除；可用 ⌘Z／Ctrl+Z 或 8 秒提示列的「復原」還原。素材庫保留分析結果，再次匯入時直接沿用。
  - **移到垃圾桶…**（Windows：移到資源回收筒…，紅框按鈕）：再開第二層確認，列出檔名與大小、數量；確認後以 send2trash 移到垃圾桶／資源回收筒（**非永久刪除**），並清除該檔快取、候選與勾選。第二層確認的預設焦點為「取消」。部分失敗（權限、唯讀磁碟）時逐一列出原因。

### 1.9 專案與續作
- 自動儲存；啟動時「繼續上次的專案？」顯示專案名、上次時間、影片數、已勾選數、未分析完的數量（自動續跑）。設定可改為自動續作或總是開新專案。
- 遺失原始檔：紅框卡「找不到原始檔…勾選與微調都已保留」＋「重新指定位置…」（選到同名檔或同雜湊檔即恢復；同資料夾其他遺失檔一併嘗試）。

### 1.10 設定（macOS：精華剪輯器 › 設定…⌘,；Windows：檔案 › 選項 Ctrl+,）
| 分頁 | 內容 |
|---|---|
| 一般 | 介面語言、啟動時（詢問續作／自動續作／開新專案）、減少動態、時間軸預設排序 |
| 推薦 | 每支推薦數 1–10、候選長度 2–10 秒、預設勾選數 0–5 |
| 音樂 | 預設音樂資料夾、預設音樂（隨機／無） |
| 效能 | 同時播放上限 4–16、硬體編碼、分析／預覽並行數（自動 = 核心數÷2）、ffmpeg 路徑與版本 |
| 智慧評分 | 本機臉部／笑容／清晰度（離線）、雲端 AI 開關（預設關）、服務、API 金鑰 |
| 素材庫 | 快取大小、監看資料夾清單、快取上限、重新分析全部、清除預覽快取 |

## 2. 使用流程
- **A 新手（零剪輯）**：拖入資料夾 → 每支 4 張會動的候選卡、自動勾選最佳 2 段 → 「產生成品」。
- **B 挑選**：瀏覽／篩選（已勾選、待分析、錯誤）→ 勾選 → 拖曳或 ⌘↑↓ 排序 → 選音樂 → 產生成品。
- **C 精修**：卡片 Enter →把手／I、O → 套用。
- **D 每日累積**：監看 DCIM 資料夾，每次打開只分析新檔，先前的勾選都在。
- **E 整理**：多選爛片 → 移除…→ 從清單移除或移到垃圾桶。
- **F 描述挑選（選用）**：開啟雲端 AI → 輸入「跳水的瞬間」→ 勾選標記「AI 相符」的卡片。

### 3.3 精修、3.4 對話框
精修：大預覽、能量曲線（候選標記／範圍把手／播放頭）、入出點、還原、套用。對話框：續作、匯入資料夾、移除（兩層）、磁碟檢查、進度、停止確認、完成、錯誤、設定。

## 5. 狀態
- **載入**：清單徽章「分析中 42%」；卡片骨架（減少動態時不閃爍）；全域「分析 3/12 支」。
- **空**：無影片 → 歡迎頁；沒有勾選 → 時間軸「勾選上方的片段卡，就會依序加入這裡」，主要按鈕停用 + 可見原因；搜尋無結果 →「沒有符合的影片」。
- **錯誤**：錯誤卡 `border:2px solid #FF6B6B`：「無法開啟 VID_0004.insv：360° 原始檔需先在 Insta360 Studio 匯出成平面 MP4。」＋說明／移除；遺失卡＋重新指定位置；ffmpeg 缺失 → 啟動對話框；輸出失敗 → 原因、可複製細節、重試、關閉；垃圾桶失敗 → 逐檔原因。
- **監看**：新檔橫幅（`role=status`）。**取消**：確認後清除暫存。

## 6. 無障礙
- 全部控制項有中文可及名稱；只有圖示的按鈕有 tooltip（含平台快捷鍵，例「復原（⌘Z）」）與隱藏文字。
- Tab 順序：頂列 → 左欄（搜尋、篩選、清單一個 tab stop，roving tabindex）→ 卡片牆 → 右欄 → 時間軸 → 產生成品。分段控制與分頁為 radiogroup／tablist + roving tabindex。
- **勾選不重建**：Qt 端只發 `dataChanged`，`currentIndex` 不動；網頁模型只切換 `aria-checked`（實測焦點保留）。
- 對話框：`aria-modal`、背景 inert、開啟時焦點到主要按鈕（危險操作則到「取消」）、Tab 循環在對話框內、Esc 取消、關閉後焦點回到開啟者。Qt 端使用 `QDialog` + `QDialogButtonBox`（自動處理 Mac／Windows 按鈕順序）。
- 對比：所有文字 ≥ 4.5:1（實測最低 6.98:1，時間軸片段字）；非文字邊框 ≥ 3:1（#707070 對 #222 = 3.4:1）；焦點框 2px 白色。
- 最小字級 12px（徽章、時間軸），次要文字 13px；點擊區 ≥ 32×32（清單內小按鈕 28px 高）；hover 不縮放（outline + 亮度 1.1）。
- 減少動態：停用自動播放、骨架動畫、平滑捲動；並跟隨系統「減少動態」設定。

## 7. 技術要點
- 執行緒：`QThreadPool` 跑分析／proxy／輸出；並行數預設核心數÷2（Windows ARM 避免過熱降頻）。
- 預覽卡：`QMediaPlayer` + `QVideoWidget`（靜音、無限循環），以 `QListView` + 自訂 delegate 虛擬化；左欄超過 200 項同樣虛擬化。
- **ffmpeg 定位**：環境變數 `FFMPEG_BINARY` → 打包 `app/bin/`（**Windows ARM 打包原生 win-arm64 ffmpeg**，來源 BtbN FFmpeg-Builds `winarm64` GPL 版；macOS 用 imageio-ffmpeg 的 arm64 版或 Homebrew）→ imageio-ffmpeg → PATH。設定 › 效能顯示目前使用的版本與架構。
- 素材庫：`app/library.py`（SQLite，已實作並通過測試，見 §9）；刪除使用 `send2trash`。
- 智慧評分：`opencv-python-headless`、`mediapipe` 為選用相依（extras），缺少時功能停用不影響主流程。雲端 AI 以 `httpx` 呼叫、金鑰用 `keyring` 儲存。
- 已知限制：INSV 360° 雙魚眼不做拼接／重構圖；MediaPipe 的 Windows ARM64 wheel 可能不提供，此時臉部／笑容評分退回 OpenCV Haar（清晰度不受影響）。
