審核對象：`DESIGN.md` v4、`mockup.html`（v4）、`review/CHANGELOG_v4.md`　審核日期：2026-10-24
**方法**：不採信 changelog 的說法，全部用 headless Chrome（puppeteer-core）實測。
- 截圖：14 個畫面與對話框 × macOS 1440／1024、Windows 1440，另加互動狀態截圖

## 四、剩餘修改清單

### 必改（全部修完：功能 91→96、UI/UX 90→96）

1. **雲端 AI 同意流程（F1）**。勾選「雲端 AI」時先跳出對話框「開啟雲端 AI 挑選？」，內文：
   > 開啟後，當你按「雲端 AI 挑選」時，App 會把**每個候選片段 1–3 張 256px 關鍵影格**和**你輸入的描述文字**傳送到 **{服務名稱}**。不會上傳原始影片、聲音、檔名或位置資訊。資料如何保存與使用，依該服務的政策：［查看 {服務} 的資料政策］。費用由你的 API 帳號支付，每次約上傳 30–90 張影像。
   - 按鈕：「我了解，開啟」（主要按鈕）／「取消」，預設焦點在「取消」。
   - 金鑰還沒通過「測試連線」之前：描述框不顯示，或顯示為停用並附原因「請先在設定 › 智慧評分填入並測試金鑰」。
   - 金鑰欄旁加「測試連線」按鈕（32px 高），結果用 `role=status` 播報。
   - 每次挑選前，在描述框下方顯示「將上傳 64 張影像到 OpenAI 相容 API」。
   - 在設定裡提供「刪除已儲存的金鑰」。
2. **垃圾桶流程（F2）**。
   - 提示列文案改為「已將 3 個檔案移到垃圾桶（Windows：資源回收筒）」，按鈕改成「在垃圾桶中顯示」，不要再提供「復原」。也可以做真正的復原：macOS 用 `NSFileManager trashItem` 回傳的路徑搬回原處。
   - 第二層確認前先檢查每個檔案所在磁碟有沒有垃圾桶。如果沒有（Windows 可移除式磁碟、網路磁碟、FAT32 等），對話框改成紅色警告：「⚠ 下列 2 個檔案位於 SD 卡（E:），該磁碟沒有資源回收筒，刪除後**無法還原**。」
   - 這種情況的按鈕改為「永久刪除」（危險樣式）／「取消」，預設焦點在「取消」；另外加一個核取方塊「我了解無法還原」，勾選後才能按「永久刪除」。
3. **雲端 AI 的結果與錯誤狀態（F3）**。
   - 卡片右上角加「AI 相符 87%」標籤：底色 #1f3350、文字 #CFE3FF（對比 11:1）、12px、4px 圓角。卡片下方加一行說明（13px #B0B0B0）。
   - 描述框下方加「勾選全部相符（6）」按鈕。
   - 錯誤橫幅：「金鑰無效」「已達額度上限」「無法連線，已改用本機評分」，每種都附「重試」和「設定」按鈕。
   - 處理中顯示「AI 分析中 12/30」並提供「取消」。
4. **人臉評分說明（F4）**。統一成一種說法：要嘛隨 App 打包，要嘛另外下載；如果需要下載，按下「下載」前要說明來源網域和大小。在設定的說明文字加上：
   > 只在你的電腦上計算臉部數量、大小、笑容與清晰度分數；**不做身分辨識，不儲存臉部影像、特徵或 landmark**，素材庫只保存 0–100 的分數。

   Windows ARM 退回 Haar 時，顯示「此裝置不支援笑容偵測，只計算臉部與清晰度」。
5. **hover 樣式（N1）**。hover 改成 `border-color:#A8A8A8; filter:brightness(1.08)`，不要用黃色。黃色只留給「已勾選」，已勾選時加粗到 3px #FFC400。hover 在未勾選卡片上時，勾選圓圈可以加白色半透明底 `rgba(255,255,255,.25)`，提示「點一下就會勾選」。
6. **停用的次要按鈕（N2）**。新增 `.btn:disabled{background:#242424;color:#8A8A8A;border-color:#3A3A3A;cursor:not-allowed}`（#8A8A8A／#242424 = 4.83:1，停用元件雖不受 WCAG 對比要求，仍保持可讀）。Qt 端在 QSS 補上 `QPushButton:disabled`。
7. **⌘↩／Ctrl+Enter（N3）**。卡片和時間軸片段的 Enter 處理要先加 `if(e.metaKey||e.ctrlKey) return;`。Qt 端用 `QShortcut`，設 `Qt.ApplicationShortcut`，優先順序要高於 view 的 keyPress。
8. **抽屜焦點（N4）**。關閉時（Esc 或再按一次按鈕）把焦點還給 rail 上的按鈕。抽屜打開時：
   - 把它當成非強制回應的側邊面板，Tab 走到最後一項時回到 rail 按鈕；
   - 或者把它當成強制回應，背景設為 inert，並加 `aria-modal`。
9. **巢狀互動元件（N5）**。卡片改成 `role=group`，裡面放：
   - 真正的勾選按鈕：`role=checkbox`，32×32，就是左上角的圓圈；
   - 「微調」按鈕：可用 Tab 到達。

   整張卡片點擊仍然可以切換勾選，Space 和 Enter 的行為不變。清單的 option 列只保留文字；「說明／移除」等動作移到右鍵選單和清單下方的動作列（選取後才出現）。

### 建議（功能 +1.5、UI/UX +2）
- **F5**：同名的 `.insv`／`.lrv`／`.thm`／`.mp4` 視為同一組。刪除時列出整組（例如「VID_0001 共 3 個檔案，4.9 GB」）；匯入時只算一支，並優先用 MP4，沒有就用 LRV。
- **F6**：用電池時監看間隔改為 5 分鐘；磁碟卸載時，該監看資料夾標示「已中斷連線（SD 卡未插入）」，不要把裡面的影片都標成遺失。
- **F7**：在 M1 Mac 和 Snapdragon X 筆電實測 3 分鐘 1080p 的輸出時間，並把數字寫進 §9。
- **N6**：上傳提示改成 13px #EEEEEE，前面加雲朵或上傳圖示，後面加「詳細」連結（打開同意說明）；放在描述框下方獨立一行。
- **N7**：把手視覺寬度維持 12px，但用透明 padding 把點擊區做到 24×84（Qt 端 hit-test 用 ±12px）。
- **N8**：清單選取改成底色 #3d3520 + 左側 3px #FFC400 直條（非文字對比 9.96:1）。
- **N9**：Windows「選項」對話框用「確定／取消／套用」；Mac 維持「立即生效，沒有按鈕」或「完成」，並在對話框底部註明「變更會立即生效」。

### 可選（各 +0.5）
