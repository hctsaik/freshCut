# 精華剪輯器（FlashCut 替代）— 設計文件 v3

> 平台：macOS（Apple Silicon）、Windows on ARM。技術：Python 3 + PySide6（QtMultimedia）+ ffmpeg（imageio-ffmpeg 內建）。介面語言：繁體中文。
> 核心理念：**「匯入 → 勾選 → 產生成品」三步完成**；想細修時，每一步都能手動接管。

## 1. 功能清單

### 1.1 匯入
- 不限數量匯入 MP4 / MOV / M4V / Insta360 `.LRV`；`.INSV` 以 MP4 嘗試開啟，失敗時顯示說明（請先在 Insta360 Studio/App 匯出平面 MP4）。
- 拖放檔案或資料夾到視窗任何位置；「＋ 匯入影片」按鈕（⌘/Ctrl+O）。
- 重複檔案自動略過並提示；無法解碼的檔案顯示錯誤卡片（含原因、「移除」按鈕），不中斷其他檔案。
- 背景平行分析（最多 CPU 核心數−1 個工作），每支影片卡片顯示「分析中 n%」。

### 1.2 自動候選片段（每支影片）
- 匯入後自動產生 **N 段候選**（預設 4，可設 3–5，設定可調 1–10），候選長度預設 4 秒（2–10 秒可調）。
- 演算法：ffmpeg 抽 2fps 64×36 灰階影格 → 畫面差異（動態）＋ 0.5 秒窗 RMS 音量 ＋ 場景切換加分 → 平滑 → 取不重疊最高分窗，起點對齊附近場景切換。
- 每個候選為一張**迷你影片預覽卡**：ffmpeg 產生 180p / 15fps / 靜音 / 循環 proxy MP4；卡片進入可視範圍即自動靜音循環播放（同時最多播放 8 張以省電，其餘顯示首格）；滑鼠移入時放大 1.05× 並從頭播放。
- 卡片資訊：時間區間「00:12.5 – 00:16.5」、長度、AI 分數星等（★1–5）、勾選框。
- 卡片動作：勾選／取消（點卡片或空白鍵）、「微調」開啟精修面板、「⋯」選單（複製、刪除、在大預覽播放）。
- 「＋ 手動新增片段」：在大預覽中標記入點 I／出點 O 後加入，與 AI 候選同等對待。
- 「重新推薦」：可針對單支影片以不同數量／長度重算，保留已勾選的片段。

### 1.3 精修（Trim）面板
- 大預覽播放器（有聲）＋ 迷你時間軸：顯示整支影片的能量曲線（動態＋音量）、候選位置、目前選取範圍（可拖曳左右把手）。
- 數值輸入入點／出點（0.1 秒精度），←/→ 逐格、Shift+←/→ 1 秒；I / O 設定；「播放此段」（循環）。
- 修改後自動重產 proxy；「還原 AI 建議」。

### 1.4 時間軸（成品順序）
- 底部橫向時間軸，勾選的片段依「匯入順序 → 時間」自動加入；寬度依長度等比例。
- 拖曳重新排序；快速排序選單：依拍攝時間 / 依匯入順序 / 依 AI 分數。
- 顯示總長度與目標長度（例如「已選 38.0 秒 / 目標 30 秒」超出以橘色提示，不阻擋）。
- 片段上：移除（×，等同取消勾選）、雙擊 → 精修。
- 「預覽成品」：用低解析度 proxy 快速串播（含轉場近似）。

### 1.5 輸出設定（右側「成品設定」面板，均有預設值）
- 畫面比例：16:9 / 9:16 / 1:1（置中裁切；預覽卡顯示裁切框疊圖）。
- 解析度：1080p（預設）/ 4K；FPS 30（進階：24/60）。
- 轉場：交叉淡化（預設 0.5 秒）/ 無；長度 0.2–1.5 秒。
- 背景音樂：選擇檔案，或「預設音樂資料夾」（記憶於設定；下拉列出資料夾內 mp3/m4a/wav/flac/aac/ogg，另有「隨機」）。音樂自動循環／裁切為影片長度，結尾自動淡出。
- 音量：音樂音量滑桿、原始聲音音量滑桿、「保留原音」開關。
- 結尾淡出：0–5 秒（預設 1.5 秒，影像與聲音同步）。

### 1.6 產生成品
- 右下角唯一主要按鈕 **「產生成品」**（⌘/Ctrl+Enter），未勾選片段時停用並提示「請至少勾選 1 個片段」。
- 點擊 → 選擇儲存位置（預設：「精華_YYYYMMDD_HHMM.mp4」於上次輸出資料夾）→ 進度對話框（整體進度條、目前步驟「處理片段 3/12」「合併與轉場」、剩餘時間估計、取消）。
- 完成 → 對話框：「在 Finder/檔案總管中顯示」「播放」「再做一支」。
- 輸出：H.264 + AAC MP4、faststart。

### 1.7 專案
- 自動儲存專案（JSON：影片路徑、片段、設定）；重開 App 詢問「繼續上次的專案？」。⌘/Ctrl+S 另存專案、⌘/Ctrl+Shift+O 開啟。
- 原始檔遺失時卡片標紅並提供「重新指定位置」。

## 2. 使用流程

**A. 新手快速流程（3 步、零剪輯）**：拖入影片 → 每支影片自動出現 4 張會動的候選卡，預設**已勾選每支的最佳 2 段** → 按「產生成品」。
**B. 挑選流程**：瀏覽卡片 → 勾選喜歡的 → 底部時間軸拖曳排序 → 選音樂 → 產生成品。
**C. 精修流程**：卡片「微調」→ 拖曳把手／I、O → 套用 → 產生成品。
**D. 手動流程**：左側點影片 → 大預覽中 I / O → 「加入片段」。

## 5. 狀態
- **載入**：影片卡片骨架 + 「分析中 42%」；候選卡在 proxy 完成前顯示縮圖 + 旋轉圖示；全域狀態列「分析 3/12 支影片」。
- **空**：無影片 → 歡迎拖放區；有影片但未勾選 → 時間軸顯示「勾選上方片段卡加入成品」，主要按鈕停用並說明原因。
- **錯誤**：無法開啟 → 卡片紅框＋原因＋「移除」；INSV 失敗 → 專屬說明連結；ffmpeg 缺失 → 啟動時對話框說明解法；輸出失敗 → 顯示可複製的錯誤細節＋「重試」；磁碟空間不足預估提醒。
- **取消**：輸出可隨時取消，清除暫存檔。

## 6. 無障礙
- 所有控制項有 accessibleName（中文）；完整鍵盤操作（Tab 順序：頂列 → 影片清單 → 卡片牆 → 設定 → 時間軸 → 產生成品）。
- 焦點框 2px 高對比；文字對比 ≥ 4.5:1；勾選狀態不只靠顏色（✓ 圖示 + 邊框）。
- 「減少動態」設定：停用自動播放，改為滑鼠移入/焦點時才播放。
- 字級跟隨系統縮放；最小點擊區 32×32。

## 7. 技術要點
- 工作執行緒（QThreadPool）跑分析/proxy/輸出，UI 不卡頓；proxy 快取於系統暫存資料夾（依檔案路徑+mtime+區間雜湊）。
- 預覽卡用 QMediaPlayer + QVideoWidget（靜音、loops=Infinite），可視範圍外暫停並釋放。
- ffmpeg 定位：環境變數 → 打包 bin/ → imageio-ffmpeg → 系統 PATH / Homebrew。
- 已知限制：INSV 360° 雙魚眼不做拼接/重構圖；Windows ARM 上 imageio-ffmpeg 為 x64 版本，經系統模擬執行（較慢，可自行放置原生 ARM64 ffmpeg 於 `app/bin/`）。

| 回合 | 評審 | 主要意見 | 修正 |
|---|---|---|---|
| 1 | 新手 Insta360 使用者 | 一開始不知道要做什麼；靜態縮圖看不出精彩處 | 歡迎拖放區；迷你影片預覽；預設勾選每支最佳 2 段 → 3 步完成 |

| 2 | 新手 | 不懂「目標長度」；擔心做錯 | 時間軸顯示已選/目標、復原重做、自動儲存 |
| 2 | 專業剪輯師 | 想快速排序、看裁切結果 | 排序選單、比例裁切框疊圖、預覽成品 |
| 2 | UX 設計師 | 大量卡片同時播放耗電、動態敏感 | 同時最多 8 張、減少動態設定、無障礙第 6 節 |
