## 1. 實測結果

### 1.2 主流程（腳本 /tmp/r10/flow.py，用 QTest 操作）

## 2. 程式品質（讀快照程式碼）
- **結構**：分成 core、library、ai/*、gui/*，分層清楚。
- **執行緒**
  - 用 QThreadPool 加 QRunnable，從 worker 送 signal 回來，每個 worker 各開自己的 SQLite 連線，做法正確。
  - 取消旗標用 threading.local，ffmpeg 的 stderr 用獨立執行緒讀取，避免死鎖，也都正確。
- **錯誤處理**：有 B1、B2、B7 三個問題，而且錯誤路徑和取消路徑的狀態清理不對稱。library.py 裡有幾處寬鬆的 except（第 94、106、166、360、616 行附近）【推論：可能吞掉錯誤】。
- **資源釋放**：取消時會刪掉半成品（但這正是 B1 誤刪舊檔的原因）；預覽暫存檔放在 cache 裡。
- **測試**：11 個檔案，涵蓋核心功能、GUI 和取消，兩次都穩定通過。但沒有測到 B1（覆寫舊檔後取消）和 B2（失敗後的狀態）這兩條路徑；語意搜尋在這個環境裡被 SKIP。

## 3. 和 FlashCut 的比較（只用公開資料加本 App 實測，**FlashCut 本身無法實測**）
- **我核對過的公開資料**
  - insta360.com 的 post 19659：FlashCut 有主題模板（vlog、life、travel、sports），每個模板需要 4–5 段素材，成品約 15 秒以內；Freestyle 模式可選短、中、長。官方原文寫 "FlashCut can only edit flat content, not 360 content"。
  - 論壇 post 8518：FlashCut 不支援短於 3 秒的影片；AI Trim 需要 1 分鐘以上的平面影片。
- **FLASHCUT_COMPARE.md 的說法核對**
  - 「360 不支援」：屬實。
  - **「❌ 沒有鎖定＋重洗」已經過時**：快照裡有「換一批」(a_shuffle)、鎖定按鈕（卡片上的 🔓）和 lock_clip，截圖 a02 也看得到。
  - **比較對象不完整**：Insta360 現在的主力是 **Auto Edit**。依官方線上手冊，它支援 360 和平面素材，有智慧構圖、360 運鏡、場景辨識、音樂配對和貼紙。如果拿 Auto Edit 比，本 App 在 360 這一項的優勢就不成立。
- **本 App 實測得到的優勢**
  - 離線執行。
  - 可以用桌面長片和大量素材，實測 3 支影片做出 18 秒和 24 秒的成品。
  - 成品長度可以自訂，可以逐段微調和排序。
- **劣勢**
  - 測試素材是合成的，主觀的精彩度無法比較。
  - B5 證明低品質片段也會被選進成品。
  - 沒有物件或人物追蹤構圖（文件自己也承認是用亮度或動態）。
  - 音樂是合成的 CC0，沒有授權曲庫。
  - CLIP 搜尋這次沒有驗證到。
- **【推論】**：如果比的是「可控性和桌面工作流程」，本 App 較強；如果比的是「自動剪出的成品好不好看」，現有證據不足以說它勝過 FlashCut，跟 Auto Edit 比更是不足。

## 5. 必改
1. **B1**：`main.py:689-690` 只能刪除這次工作自己產生的檔案。`core.export` 改成先輸出到 `out+'.part'`，完成後再 `os.replace`（`core.py:521`）。
2. **B2**：`main.py:441-443` 的 `_analyze_failed` 要清掉 `_after_analysis = None` 和 `_an_queue = []`，並補測試。
3. **B3**：`style.py` 讓已勾選卡片的焦點有明顯變化，例如白色外框或 outline，和勾選邊框的對比要 ≥3:1。
4. **B4**：用 setTabOrder 把順序改成「清單 → 卡片牆 → 時間軸 → 設定 → 預覽/產生」，並把 QScrollArea 設成 `setFocusPolicy(Qt.NoFocus)`。

## 6. 建議
- B5：設最低分門檻（例如 score 小於 0.3 不自動勾選），或在卡片上加標註。
- B6：重新勾選時放回原本的位置。
- B7：顯示友善的錯誤訊息，細節收在「詳細資料」裡。
- B8：時間軸項目加寬或改用 elide，toast 避開時間軸。
- 停用輸入框的邊框提高到 ≥3:1。
- 更新 FLASHCUT_COMPARE.md：修正鎖定/重洗那一項，並加入 Auto Edit 的比較。
